# Demo script

Target length: **90–100 seconds** for a narrated walkthrough. The automated recorder produces a silent 1080p MP4 of about 70 seconds at `demo/sigma-broadcast-demo.mp4`; record a voiceover from this script if the submission format allows it, or use a manual capture for exact timing.

## Before recording

```bash
npm ci
npm run build
npm run demo:record
```

`npm run demo:record` starts the dev server, fast-forwards quiet spells, slows to 16× while an overlay is on screen, waits for full time, scrolls to the recap and converts the WebM to MP4 with ffmpeg. Set `DEMO_HEADED=1` to watch it. To record an already running instance:

```bash
$env:DEMO_URL="http://localhost:5173"; npm run demo:record
```

## Key talking points

- The deterministic director is still the scheduling authority in advisory mode.
- The MLP is trained offline and runs in the browser; no network is required.
- The LLM is optional and never changes scheduling.
- Personalization is explicit, local and evidence-based.
- The output route is transparent and OBS-ready.
- Application Insights tracks product events, not prompts or personal data.

## If the LLM is not configured

Say: "The demo runs fully on-device. The LLM path is wired for Azure OpenAI and GitHub Models; without credentials the narrator uses the same grounded on-device explanation and a deterministic recap."

## If the match is already finished

Click **Reset**, then **Play match** before starting the recording. The recorder starts from a fresh page, so this only matters for a manual capture.
